📚 What is Simon's Algorithm?

Simon's algorithm solves the problem of finding a hidden string s where a function f(x) = f(x ⊕ s). It demonstrates exponential quantum speedup: O(n) quantum queries vs O(2n) classical queries!

Algorithm Steps:

Step 1: Initialization
Start with |0⟩⊗2n state (all qubits in |0⟩)
Step 2: Hadamard Transform
Apply H⊗n to input register to create equal superposition of all 2n inputs
Step 3: Oracle Query
Apply oracle Uf: |x⟩|0⟩ → |x⟩|f(x)⟩ where f(x) = f(x ⊕ s)
Step 4: Second Hadamard
Apply H⊗n to input register to create interference
Step 5: Measurement
Measure input register to obtain y where y·s = 0 (mod 2)

🎯 Key Insight

The algorithm returns strings that are orthogonal to the secret in binary space (GF(2)). By collecting n-1 linearly independent measurements, we can solve for the secret string s!

Quantum Advantage: Classical algorithms need ~2n/2 queries, but Simon's algorithm needs only O(n) queries - exponential speedup! 🚀
